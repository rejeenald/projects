# Required external tools:

## GhostScript

  
**Download and install from:**  
[https://www.ghostscript.com/download/gsdnld.html](https://www.ghostscript.com/download/gsdnld.html)

**After installing, confirm it's available by running this in Command Prompt:**

make sure to close the terminals or close the VScode or any application using a terminal.
```
gswin64c -v
```
