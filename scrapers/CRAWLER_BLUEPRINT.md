# Crawler Blueprint

How the crawlers in this folder are structured and built, written down so new crawlers can follow the same technique, process, and flow.

The source projects are:

| Project | Spider | Target type | Rendering | Notable technique |
|---|---|---|---|---|
| `ce_naco_org/` | `ce_naco` | Map page → per-county profile pages | **JS (Selenium via `scrapyium`)** | `js-https://` scheme, `navigate_cb`, custom retry + `errback` |
| `metacritic_com/` | `metacritic` | Year listings → movie → user/critic reviews | Plain HTTP | Generated seed URLs, multi-level pagination, two item types → two CSVs |
| `myip_ms/` | `myip_ms` | Paginated table | Plain HTTP + fixed headers/cookie | Read last page number from inline `<script>`, generate all page URLs up front |

---

## 1. Tech stack

- **Scrapy** 2.2–2.4 (`scrapy startproject` layout).
- **Internal libraries** from the private index (`--extra-index-url https://<token>:@pypi.fury.io/wordbean-2019`):
  - `orca_skips`: proxy rotation (`ProxyNetMiddleware`) and User-Agent rotation (`RotateUserAgentMiddleware`).
  - `cherry_apples`: output processors (`strip_strings`, `remove_emptys`, `remove_duplicates`), `SmartSampleMiddleware`, `DebuggingMiddleware`, `MultiItemOutputPipeline`.
  - `scrapyium`: Selenium-backed download handler for JS pages (`ScrapyiumRequest`, `ScrapyiumDownloader`, `RescueRequestDataException`).
- **Testing**: `pytest==4.0`, `pytest-describe`, `scrapy_tdd` (`mock_response_from_sample_file`, `my_path`, `urls_from_requests`).
- **Deployment**: `scrapyd-client` (`scrapyd-deploy`) to an internal scrapyd server.
- **Output**: CSV feeds (`FEED_FORMAT = 'csv'`).

---

## 2. Project layout

Every crawler is a separate Scrapy project named after the domain, using `snake_case` with the dot replaced by an underscore (`ce.naco.org` → `ce_naco_org`, `metacritic.com` → `metacritic_com`).

```
<domain_tld>/
├── requirements.txt          # private index + orca_skips/cherry_apples(/scrapyium) + scrapy + test libs
├── scrapy.cfg                # [settings] + [deploy] target
├── setup.py                  # generated by scrapyd-deploy (egg entry point)
└── <domain_tld>/
    ├── __init__.py
    ├── items.py              # Item classes + Field presets (DEFAULT / NUMBER / LIST)
    ├── middlewares.py        # Scrapy template, normally left untouched
    ├── pipelines.py          # Scrapy template, unless multi-item output is needed
    ├── settings.py           # throttling, retries, proxies, UA rotation, (scrapyium), feeds
    ├── spiders/
    │   ├── __init__.py
    │   └── <short_name>.py   # one spider per project
    └── tests/                # (metacritic keeps tests/ at project root; myip_ms keeps them in spiders/)
        ├── __init__.py
        ├── test_spider.py
        └── samples/          # saved HTML pages used as test fixtures
            └── *.html
```

**Standard to follow for new crawlers:** put tests in `<domain_tld>/<domain_tld>/tests/` with a `samples/` folder, as `ce_naco_org` does.

## 3. Build process (step by step)

This is the order the existing crawlers were built in. It is test-driven: save sample pages, write the extraction, then lock it in with tests.

1. **Scaffold**
   ```bash
   scrapy startproject <domain_tld>
   cd <domain_tld>
   scrapy genspider <short_name> <domain>
   ```
2. **Set up `requirements.txt`** with the private index and internal libs (template in §9), then `pip install -r requirements.txt`.
3. **Analyse the site and map out the crawl flow.** Decide:
   - the **entry point**: a single start URL, or URLs you generate (years, IDs, page numbers),
   - the **listing level(s)**: the pages that give you links or IDs,
   - the **detail level(s)**: the pages that give you the data,
   - **pagination**: a "next" link, or a known last page number,
   - whether the pages need **JS rendering**. If they do, use `scrapyium`.
4. **Save sample HTML** for every page type and edge case into `tests/samples/`. Use descriptive file names that state the case, for example `no next page - ....html`, `county_missing_website_url.html`, `knox_county_using_old_xpaths.html`.
5. **Define the Items** in `items.py` (§5). Write one field per output column, and use `src` for the source URL.
6. **Write the spider** (§4). Use one callback per page type, and put extraction in small helper methods (`_extract_*`, `build_*`, `get_*`) so tests can call them directly.
7. **Write tests** against the samples (§7) and run `pytest`.
8. **Configure `settings.py`** (§6): delay, concurrency, retries, proxies, UA rotation, sample mode, and output.
9. **Run a small-sample crawl** (`SMALL_SAMPLE_MODE = True` or `SMART_SAMPLE_ACTIVE = True`) and inspect the CSV:
   ```bash
   scrapy crawl <short_name> -o sample.csv
   ```
10. **Run the full crawl.** Turn sample mode off, then run locally or deploy to scrapyd (§8).
11. **Post-process if needed.** For example, `myip_ms/cleanup.py` uses pandas to merge runs, de-duplicate, and select columns.

## 4. Spider structure and flow

### 4.1 Canonical flow

```
start_requests()
   │  seed request(s): one start URL, or generated URLs (years / IDs / pages)
   ▼
parse_<listing>(response)            # e.g. parse_counties, parse_movie_urls, parse_pages
   │  extract IDs / links (deduplicate)
   │  build one Request per detail page, passing context via meta
   │  append the next-page Request (if any)
   ▼
parse_<detail>(response)             # e.g. parse_county_data, parse_movie_reviews, parse_page_data
   │  validate the response (expected URL / key element present?) → else _retry_request(meta)
   │  ItemLoader(Item(), response) → add_value / add_xpath
   │  return list of items (+ next-page Request)
   ▼
_on_error(failure)                   # errback: classify failure, rebuild request, retry
```

### 4.2 Conventions used in every spider

- **Base class**: `scrapy.Spider` or `CrawlSpider`. `CrawlSpider` is used, but no `rules` are defined, so it behaves like `Spider`. For new crawlers, use `scrapy.Spider` unless you actually need `rules`.
- **`name`** is the short site name (`'ce_naco'`, `'metacritic'`, `'myip_ms'`).
- **Use `start_requests()`**, not `start_urls`. It returns a **list** of requests.
- **Callbacks return lists** (`results = []`, `requests = []` … `return results`) rather than using `yield`. The tests depend on this, because they index into the result (`parse_x(resp)[0]`, `len(results)`).
- **One callback per page type**, named `parse_<thing>`.
- **Helpers** (`_extract_county_ids`, `_get_last_page_number`, `build_next_page_*_url`, `extract_all_reviews`, `get_review_full_text`) hold the XPath logic. They are public or underscore-private and take `response` or a selector, so they can be unit tested.
- **State travels in `meta`**: IDs, page numbers, retry counters, the original URL (`'id'`, `'county_url'`, `'retry'`, `'movie_id'`, `'movie_page_number'`, `'review_page_number'`).
- **Use XPath only** (no CSS selectors). Use `.extract_first()` / `.extract()`, `contains(@class, ...)`, and label-anchored XPaths such as:
  ```xpath
  ./td//b[contains(text(), 'DNS Records:')]/parent::div/following::div[@class='sval'][position()=1]/a/text()
  ```
- **Absolute URLs** are built by joining the site root with the relative href: `"".join(['https://www.metacritic.com', href])`. For new code, `response.urljoin(href)` is preferred and does the same thing.
- **Log every step** with `logging.info(...)`: entering a callback, counts extracted, next page found, and retries. Use `logging.warning` for unexpected but recoverable cases and `logging.error` in errbacks.
- **Every item gets `src = response.url`.**

### 4.3 Seed generation patterns

**A. Generated seed URLs (metacritic):** build them in `__init__`, and narrow them down in `start_requests` when sample mode is on.
```python
def __init__(self, *args, **kwargs):
    super().__init__(*args, **kwargs)
    self.seed_urls = self.build_seed_urls()

def build_seed_urls(self):
    return ["https://site.com/list?year={}".format(y) for y in range(2005, 2020)]

def start_requests(self):
    if self.settings.get('SMALL_SAMPLE_MODE'):
        self.seed_urls = self.seed_urls[-1:]
    return [Request(u, callback=self.parse_listing, meta={'page_number': 1}) for u in self.seed_urls]
```

**B. Single entry → IDs scraped from the page (ce_naco):** the entry page lists every ID, so deduplicate them, skip the known invalid ones, and fan out one request per ID.
```python
county_ids = response.xpath("//*[@class='svg-county']/@id").extract()
county_ids = list(dict.fromkeys(county_ids))   # order-preserving dedupe
```

**C. Last page number → generate every page URL (myip_ms):** read the total page count once (here it comes from an inline `<script>` call such as `paging_init(...)`), then build every page request up front.
```python
script_text = response.xpath("//script[contains(text(), 'paging_init')]/text()").extract_first()
last_page = int(script_text.split(",")[5].strip().strip("'"))
return [Request(self.page_url.format(n), callback=self.parse_page_data, headers=self.headers)
        for n in range(1, last_page + 1)]
```

### 4.4 Pagination ("next" link) pattern

Each paginated level has its own `build_next_page_<level>_url(response)`. It returns a `Request` or `None`, increments a page counter in meta, and stops after page 2 when sample mode is on.
```python
def build_next_page_review_url(self, response):
    next_href = response.xpath("//*[@class='action'][@rel='next']/@href").extract_first()
    logging.info("Extracting next page url...")
    if not next_href:
        return None
    meta = dict(response.meta)
    meta['review_page_number'] = meta['review_page_number'] + 1
    if self.settings.get('SMALL_SAMPLE_MODE') and meta['review_page_number'] > 2:
        logging.info("Stopped the extraction of reviews after page 2.")
        return None
    return Request(response.urljoin(next_href), callback=self.parse_movie_reviews, meta=meta)
```
The callback then does:
```python
next_page = self.build_next_page_review_url(response)
if next_page is not None:
    results.append(next_page)
return results
```

### 4.5 Repeating blocks / rows

To parse lists of reviews or table rows, loop over the row selectors and build **one ItemLoader per row**. Use relative XPaths (`.//`) on the row selector, and track the position with a counter (`appearance_order_of_review`).

If each record spans two `<tr>`s (a visible row plus a toggled detail row, as in myip_ms), step through the rows two at a time and pass both rows to separate helpers:
```python
rows = response.xpath("//*[@id='sites_tbl']/tbody/tr")
for i in range(0, len(rows), 2):
    l = ItemLoader(MyItem(), response)
    l.add_value("src", response.url)
    self._extract_data_in_visible_row(l, i, rows)
    self._extract_data_in_toggled_row(l, i, rows)
    results.append(l.load_item())
```

### 4.6 Branching on page variant

One callback can handle several variants of a page. Detect the variant from the URL or from an element on the page, then branch:
- `get_type_of_review(url)` checks for `'user-review' in url` to tell user reviews from critic reviews, and the extracted fields differ by type.
- `get_review_full_text` takes the "Expand" toggle's expanded blurb if the toggle is present, otherwise the plain body. It takes the "Read full" link's summary if that link is present, otherwise the plain summary.
- The ce_naco tests keep samples for **old and new XPaths** (`knox_county_using_old_xpaths.html`, `crawford_county_using_new_xpath.html`). When a site changes its markup, keep both variants under test.

### 4.7 JS-rendered sites (scrapyium pattern, from ce_naco)

1. Prefix the URL with **`js-`** (`js-https://...`). The `DOWNLOAD_HANDLERS` setting routes those schemes to `ScrapyiumDownloader`.
2. Use **`ScrapyiumRequest`** instead of `Request`.
3. Optional **`navigate_cb(response, scrapyium)`** runs inside the browser before the response is returned. Use it to wait or scroll when a lazy-loaded element is missing:
   ```python
   def navigate_detail_page(self, response, scrapyium):
       if not response.xpath('<key element xpath>'):
           scrapyium.natural_wait(5)
           scrapyium.driver.execute_script("window.scrollTo(0, document.body.scrollHeight);")
           scrapyium.natural_wait(5)
   ```
4. Add **`RescueRequestDataException`** to the errback's failure checks. The rescued request is at `failure.value.request`.
5. Add the scrapyium settings block (§6).

### 4.8 Response validation and retry (ce_naco)

Don't trust a 200 response. Check that the response really is the page you asked for:
```python
def parse_detail(self, response):
    meta = response.meta
    if 'county_info' not in response.url:                 # got redirected
        logging.warning("Unexpected response %s for id %s" % (response.url, meta['id']))
        return self._retry_request(meta)
    key_value = response.xpath("<key element>/text()").extract_first()
    if not key_value:                                      # page not fully loaded / blocked
        logging.warning("Key element missing for id %s" % meta['id'])
        return self._retry_request(meta)
    return self._load_item(key_value, response, meta)

def _retry_request(self, meta):
    meta['retry'] = meta['retry'] + 1
    return ScrapyiumRequest(meta['detail_url'], callback=self.parse_detail, meta=meta,
                            errback=self._on_error, dont_filter=True)
```
- Store the **original URL in meta** (`'county_url'`) so a retry can rebuild the request even after a redirect.
- Use **`dont_filter=True`** on retries, otherwise the dupe filter drops them.
- Write the **retry count to the item** (`retry` field) so you can see in the CSV how hard each record was to get.

### 4.9 Errback (ce_naco)

```python
def _on_error(self, failure):
    url, meta, error_message = self._extract_data_from_failure(failure)
    if error_message:
        logging.error(error_message)
    if not url:
        logging.error("Cannot retry request because it has no URL.")
        return
    meta['retry'] = meta.get('retry', 0) + 1
    callback = self.parse_detail if '<detail marker>' in url else self.parse_listing
    return Request(url, callback=callback, meta=meta, errback=self._on_error, dont_filter=True)

def _extract_data_from_failure(self, failure):
    response, request, error_message = None, None, ''
    if failure.check(HttpError):
        response = failure.value.response
        error_message = 'HttpError on %s' % response.url
    elif failure.check(DNSLookupError):
        request = failure.request
        error_message = 'DNSLookupError on %s' % request.url
    elif failure.check(TimeoutError, TCPTimedOutError):
        request = failure.request
        error_message = 'TimeoutError on %s' % request.url
    elif failure.check(RescueRequestDataException):        # scrapyium only
        request = failure.value.request
        error_message = 'RescueRequestDataException on %s' % request.url
    if response:
        return response.url, response.meta, error_message
    if request:
        return request.url, request.meta, error_message
    return None, dict(), error_message
```
Route the retry back to the right callback by looking at the URL. For JS sites, rebuild the retry as a `ScrapyiumRequest` with the `js-` URL.

### 4.10 Fixed headers / session cookie (myip_ms)

When a site blocks bare requests, copy the browser's request headers (including the `Cookie`) into a class-level `headers` dict and pass `headers=self.headers` on every `Request`. Set `meta={'dont_merge_cookies': True}` so Scrapy doesn't overwrite the cookie, and set `COOKIES_ENABLED = False`. The cookie expires, so it has to be refreshed by hand.

## 5. Items and field processors

Items always go through an **`ItemLoader`** using **output processors only**. The `cherry_apples` processors flatten the extracted lists into clean strings.

```python
import re
import scrapy
from itemloaders.processors import Join, Compose        # older projects: scrapy.loader.processors
from cherry_apples.processors.output import *            # strip_strings, remove_emptys, remove_duplicates

DEFAULT = scrapy.Field(output_processor=Compose(
    strip_strings, remove_emptys, remove_duplicates, Join(' '),
))

def strip_non_integers(in_list):
    return [re.sub('[^0-9.]+', '', s) for s in in_list]

def convert_to_integer(value):
    try:
        return int(value)
    except ValueError:
        return float(value)

NUMBER = scrapy.Field(output_processor=Compose(
    strip_non_integers, remove_emptys, Join(' '), convert_to_integer,
))

LIST = scrapy.Field()   # keep raw list (e.g. dns_records)
```

Rules used in the existing items:
- Use **one Item class per output entity** (`MetacriticMovieItem`, `MovieReviewsItem`).
- Name fields in **snake_case, descriptively** (`no_of_users_who_found_the_review_helpful`, `url_to_read_full_text_of_critic_review`), because they become the CSV headers.
- Every item includes **`src`**. ID and context fields (`id`, `movie_id`, `*_page_number`, `retry`) are included for traceability.
- Use **field-specific cleaners** where needed, by composing extra functions onto the default chain:
  ```python
  def fix_null_href(text):
      return '' if text == 'null' else text

  county_website_url = scrapy.Field(output_processor=Compose(
      strip_strings, remove_emptys, Join(' '), fix_null_href,
  ))
  ```
- Leave a field as `DEFAULT` instead of `NUMBER` when it can hold text such as `"TBD"`, and say so in a comment.
- Group fields with comments (`# user reviews`, `# NOT AVAILABLE ON CRITIC REVIEWS`).

Loading:
```python
l = ItemLoader(MyItem(), response)
l.add_value('src', response.url)
l.add_value('id', str(meta['id']))
l.add_xpath('title', "//h1/text()")
l.add_value('website', response.xpath("...").extract_first())
return l.load_item()
```
If you need a computed field that depends on others, read them back with `l.get_output_value('field')`, as metacritic does to sum the positive, mixed, and negative counts.

## 7. Testing (TDD with saved samples)

Tests use `pytest-describe` (nested `describe_*` / `should_*` functions) and `scrapy_tdd`. They load saved HTML as fake responses and call the spider methods directly, with no network access.

```python
from scrapy.utils.test import get_crawler
from scrapy_tdd import *
import pytest

from <domain_tld>.spiders.<short_name> import <SpiderClass>

def response_from(file_name, url="https://<site>/", meta=None):
    return mock_response_from_sample_file(my_path(__file__) + "/samples", file_name, url=url, meta=meta)

def describe_<short_name>_spider():
    to_test = <SpiderClass>.from_crawler(get_crawler())   # gives the spider .settings

    def describe_listing_page():
        resp = response_from("listing.html")
        resp.meta['page_number'] = 1
        requests = to_test.parse_listing(resp)
        urls = urls_from_requests(requests)

        def should_return_detail_requests():
            assert len(urls) == 101            # detail links + 1 next page

        def describe_no_next_page():
            resp = response_from("no next page - listing.html")
            def should_return_none():
                assert not to_test.build_next_page_url(resp)

    def describe_detail_page():
        resp = response_from("detail.html", url="https://<site>/item/123")
        resp.meta['id'] = '123'
        resp.meta['retry'] = 1
        item = to_test.parse_detail(resp)

        def should_return_item_fields():
            assert item['name'] == 'Expected Name'
            assert item['src'] == 'https://<site>/item/123'

    def describe_missing_field_edge_case():
        resp = response_from("detail_missing_website.html", url="...")
        resp.meta.update({'id': '1', 'retry': 1})
        def should_return_empty_string():
            assert to_test.parse_detail(resp)['website'] == ''
```

What gets tested:
- Seed URL generation: count, first and last values, and an out-of-range value that must **not** be present.
- Number of IDs or links extracted from a listing, both before and after deduplication or exclusion.
- Next page present and next page absent.
- Every field of the first item, plus one item further down the page (for example row 25, or `reviews[12]`).
- Number of fields in an item (`len(item) == 20`).
- Number of items per page and the ordering counters (first == 1, last == N).
- Edge-case samples: a missing field, old vs. new markup, expand-toggle vs. plain text, "read full" link vs. none, and no duplicated text.
- When you use `from_crawler(get_crawler())`, `self.settings` is available in the spider (needed for `SMALL_SAMPLE_MODE`).

Run:
```bash
pytest                       # from the project root
ptw                          # pytest-watch while developing
```

## 8. Running and deployment

```bash
# local sample run
scrapy crawl <short_name> -s SMALL_SAMPLE_MODE=True -o sample.csv

# local full run
scrapy crawl <short_name> -o full_run.csv

# deploy to scrapyd (target defined in scrapy.cfg)
scrapyd-deploy            # or: scrapyd-deploy default
```

`scrapy.cfg`:
```ini
[settings]
default = <domain_tld>.settings

[deploy]
url = <scrapyd server url>
project = <domain_tld>
username = <from env / not committed>
password = <from env / not committed>
```
`setup.py` is generated by `scrapyd-deploy`. Make sure `name` and `entry_points` match the project (metacritic left `name = 'project'`; use the project name instead).

## 10. New spider skeleton

```python
import logging

import scrapy
from scrapy.http import Request
from scrapy.loader import ItemLoader
from scrapy.spidermiddlewares.httperror import HttpError
from twisted.internet.error import DNSLookupError, TimeoutError, TCPTimedOutError

from ..items import MyItem


class MySiteSpider(scrapy.Spider):
    name = 'my_site'
    base_url = 'https://www.my-site.com'

    def start_requests(self):
        url = self.base_url + "/listing"
        logging.info("Visiting the page: %s" % url)
        return [Request(url, callback=self.parse_listing, errback=self._on_error,
                        meta={'page_number': 1, 'retry': 1}, dont_filter=True)]

    # ---- listing level ------------------------------------------------------------
    def parse_listing(self, response):
        logging.info("Parsing listing page %s..." % response.meta['page_number'])
        requests = []
        for item_id, href in self._extract_detail_links(response):
            detail_url = response.urljoin(href)
            meta = {'id': item_id, 'detail_url': detail_url, 'retry': 1}
            requests.append(Request(detail_url, callback=self.parse_detail, meta=meta,
                                    errback=self._on_error))
        next_page = self.build_next_page_url(response)
        if next_page is not None:
            requests.append(next_page)
        return requests

    def _extract_detail_links(self, response):
        rows = response.xpath("//table//a[@class='title']")
        links = [(a.xpath("./@href").extract_first().rstrip('/').split('/')[-1],
                  a.xpath("./@href").extract_first()) for a in rows]
        links = list(dict.fromkeys(links))
        logging.info("There are %s detail links." % len(links))
        return links

    def build_next_page_url(self, response):
        next_href = response.xpath("//*[@rel='next']/@href").extract_first()
        if not next_href:
            return None
        meta = dict(response.meta)
        meta['page_number'] = meta['page_number'] + 1
        if self.settings.get('SMALL_SAMPLE_MODE') and meta['page_number'] > 2:
            logging.info("Stopped after page 2 (small sample mode).")
            return None
        return Request(response.urljoin(next_href), callback=self.parse_listing,
                       meta=meta, errback=self._on_error)

    # ---- detail level -------------------------------------------------------------
    def parse_detail(self, response):
        meta = response.meta
        name = response.xpath("//h1/text()").extract_first()
        if not name:
            logging.warning("Key element missing for id %s." % meta['id'])
            return self._retry_request(meta)
        return self._load_item(name, response, meta)

    def _load_item(self, name, response, meta):
        l = ItemLoader(MyItem(), response)
        l.add_value('src', response.url)
        l.add_value('id', str(meta['id']))
        l.add_value('retry', str(meta['retry']))
        l.add_value('name', name)
        l.add_xpath('website', "//*[contains(@class,'website')]//a[1]/@href")
        return l.load_item()

    def _retry_request(self, meta):
        meta['retry'] = meta['retry'] + 1
        logging.info("Retrying %s (retry %s)" % (meta['detail_url'], meta['retry']))
        return Request(meta['detail_url'], callback=self.parse_detail, meta=meta,
                       errback=self._on_error, dont_filter=True)

    # ---- errors -------------------------------------------------------------------
    def _on_error(self, failure):
        url, meta, error_message = self._extract_data_from_failure(failure)
        if error_message:
            logging.error(error_message)
        if not url:
            logging.error("Cannot retry request because it has no URL.")
            return
        meta['retry'] = meta.get('retry', 0) + 1
        callback = self.parse_detail if 'detail_url' in meta else self.parse_listing
        return Request(url, callback=callback, meta=meta, errback=self._on_error, dont_filter=True)

    def _extract_data_from_failure(self, failure):
        response, request, error_message = None, None, ''
        if failure.check(HttpError):
            response = failure.value.response
            error_message = 'HttpError on %s' % response.url
        elif failure.check(DNSLookupError):
            request = failure.request
            error_message = 'DNSLookupError on %s' % request.url
        elif failure.check(TimeoutError, TCPTimedOutError):
            request = failure.request
            error_message = 'TimeoutError on %s' % request.url
        if response:
            return response.url, response.meta, error_message
        if request:
            return request.url, request.meta, error_message
        return None, dict(), error_message
```

## 11. Checklist for each new crawler

- [ ] Project named `<domain_tld>`, with one spider and a short `name`.
- [ ] `requirements.txt` has the private index and `orca_skips` / `cherry_apples` (plus `scrapyium` if the site needs JS).
- [ ] Crawl flow mapped out: seed → listing(s) → detail(s), and the pagination type.
- [ ] Sample HTML saved for every page type and edge case, with descriptive file names.
- [ ] Items use the `DEFAULT` / `NUMBER` / `LIST` presets, and every item has `src`, an ID, and context fields.
- [ ] Callbacks return lists, with extraction in small, testable helpers.
- [ ] Context passed in `meta` (a copy per request), including the original URL and a `retry` counter.
- [ ] Responses validated (expected URL and key element present), with retries using `dont_filter=True`.
- [ ] `errback` that classifies HttpError, DNS, Timeout (and Rescue) failures and re-queues the request.
- [ ] `SMALL_SAMPLE_MODE` (or Smart Sample) supported.
- [ ] Settings: delay, concurrency, `RETRY_TIMES = 50`, wide `RETRY_HTTP_CODES`, proxies, UA rotation, CSV feed.
- [ ] Multiple entities use `MULTI_FILES` and `MultiItemOutputPipeline`.
- [ ] `pytest` passes, then a sample crawl CSV is inspected, then the full run or deploy.
- [ ] No credentials committed (see §12).

## 12. Things in the existing code **not** to copy

Avoid these when you replicate the pattern:

1. **Mutating `response.meta` in place** (`metacritic.parse_movie_urls`, `build_next_page_*`): the same dict is changed inside the loop. This only works because Scrapy's `Request` makes a shallow copy of `meta` when it is constructed. It is fragile and confusing, so build a new dict per request instead: `meta = dict(response.meta, movie_id=...)`.
2. **Class-level `_values = defaultdict(list)` and the `__setitem__` override on Items**: every item instance shares the same storage. Use plain `scrapy.Item` subclasses.
3. **Typos that silently disable code**: `def __init_` (myip_ms, so it is never called), and `ields = defaultdict(...)` (myip_ms items).
4. **`error_message = 'RescueRequestDataException on %s', request.url`** makes a tuple, not a string. Use `%`.
5. **`add_xpath("movie_page_number", str(...))`** passes a value as an XPath. Use `add_value`.
6. **Duplicate imports, a stray `print()`, unused `CrawlSpider` / `LinkExtractor` imports, and a duplicate `429` in `RETRY_HTTP_CODES`.**
7. **Hardcoded credentials** in `scrapy.cfg` (`username` / `password`), the private PyPI token in `requirements.txt`, and proxy credentials. Load these from environment variables or a non-committed file.
8. **Hardcoded session cookies** (myip_ms): they expire. If a cookie is required, prefer getting it at runtime, for example from an initial request or a scrapyium session.
